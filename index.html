[PriceMonitor] Monitoramento de Preços no Mercado Livre

Ver detalhes →
Problema

Não havia uma solução eficiente para monitorar os preços dos produtos no Mercado Livre de forma automática, com boa disponibilidade e sem custo elevado de infraestrutura.

Decisão técnica

Como a API pública não atendia a todos os requisitos, adotei uma estratégia API-first com fallback via web scraping (Java + Spring Boot), com deploy em Docker na Render e banco Postgres na Neon.

Resultado

SaaS completo em produção com histórico de preços e identificação de oportunidades de compra, incluindo solução para bloqueios de scraping por IP de datacenter e monitoramento de disponibilidade.

JavaSpring BootReact + VitePostgreSQL (Neon)DockerRender

[Monitorean] Monitoramento de Violações de Preço Mínimo (MAP)

Em desenvolvimento
Problema

Lojistas do Mercado Livre têm dificuldade para identificar rapidamente quando revendedores violam o Preço Mínimo Anunciado (MAP) de seus produtos.

Decisão técnica

Novo SaaS em Go, com frontend em React/Vite/TypeScript, para monitorar violações de MAP por EAN — solução que nasceu como conceito de plano Enterprise dentro do PriceMonitor e foi desacoplada em produto próprio.

Resultado

Arquitetura de monitoramento por EAN já implementada, evoluindo para uma ferramenta dedicada de compliance de preços para lojistas.

GoReactViteTypeScript

[Apps Mobile] Agendamento, Treinos e Notas

Ver detalhes →
Problema

Necessidade de soluções mobile simples e rápidas para gestão de agenda de barbearia, acompanhamento de treinos e captura de anotações pessoais.

Decisão técnica

Três aplicativos com Flutter no frontend e Go no backend: agendamento com prevenção de conflito de horários, rastreamento de treinos com gráficos de progresso, e captura rápida de notas com busca full-text em Postgres.

Resultado

Agendamento automatizado sem conflitos de horário, visualização da evolução dos treinos e captura de notas com busca eficiente — todos com autenticação JWT.

FlutterGoGinJWTPostgreSQL
