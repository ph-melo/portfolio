[Pricemonitor] Monitoração do Preços no Mercado Livre

Ver detalhes →
Problema

Não há uma solução eficiente para monitorar os preços dos produtos no Mercado Livre de forma automática.

Decisão técnica

Como a API pública não atendia aos requisitos, foi adotado web scraping com Java e Spring Boot para coleta automatizada de preços, com foco em escalabilidade e manutenção.

Resultado

Automatização do monitoramento de preços, permitindo acompanhar variações dos produtos, criar histórico de valores e identificar oportunidades de compra de forma mais eficiente.
